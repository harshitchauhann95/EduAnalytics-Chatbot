# 🎓 EduAnalytics-Chatbot
### Predictive Modeling for Student Success

This project uses Machine Learning (Random Forest) to predict final student grades based on social and academic factors. It includes a live **Streamlit** web interface for real-time predictions.

## 🚀 Features
- **Predictive Engine:** Trained on the UCI Student Performance dataset.
- **Data Pipeline:** Automated Label Encoding and Feature Engineering.
- **Web Interface:** Interactive chatbot built with Streamlit.
- **Validation:** Verified using K-Fold Cross-Validation for stability.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, Scikit-Learn, Streamlit, Pickle
- **Environment:** Jupyter Notebook / MacBook Air

## 📈 Model Performance
- **Primary Algorithm:** Random Forest Regressor
- **Accuracy Metric:** R-squared & Mean Absolute Error validation included.
